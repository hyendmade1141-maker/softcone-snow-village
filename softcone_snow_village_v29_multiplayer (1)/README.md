# 소프트콘 눈마을 v29 — 실시간 멀티플레이

같은 링크로 접속한 친구들이 한 마을에서 실시간으로 움직이고, 소원 감튀와 심은 소프트콘을 공유합니다.

## 실행

Node.js 18 이상 설치 후, 이 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 열기. **index.html을 직접 열면 멀티플레이가 작동하지 않습니다.**

## 친구에게 링크 공유하기

Render/Railway/Fly.io 등 Node.js 서버 호스팅에 이 프로젝트를 업로드하고 `npm start`를 실행하세요. 발급된 HTTPS URL을 공유하면 됩니다. 이 압축파일 자체에는 공개 서버나 URL이 포함되어 있지 않습니다.

## 데이터

소원/소프트콘은 `server/village-data.json`에 저장됩니다. 배포 서비스에서 영구 디스크를 설정하지 않으면 재배포 시 데이터가 초기화될 수 있습니다. 대규모 서비스에는 별도 DB와 로그인/권한 관리가 필요합니다.

## 유의사항

같은 브라우저의 동일한 사용자 ID는 같은 소유자로 간주됩니다. 운영 서비스에는 사용자 인증과 스팸 방지 기능을 추가해야 합니다. 현재 버전은 소규모 친구 테스트용입니다.
